# bdf-smoke-repo

Repo mínimo para validar la configuración de AgentSky (instalación del stub de `bit`, escritura en el workspace, recuperación de cambios). No contiene código ni datos reales.

Contiene un stub de `bit` (`tools/bit-stub.sh`), un cambio de ejemplo (`openspec/changes/demo-hola`) y un script de verificación (`tools/verify-setup.sh`) que no usa el modelo para razonar, solo ejecuta comandos de shell.
